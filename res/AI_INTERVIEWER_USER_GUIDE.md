# AI Interviewer - Quick User Guide

## 🎤 Enhanced Speech-to-Text Features

### How to Use Voice Input

1. **Start Recording**
   - Click the microphone button (🎤) in the answer input area
   - Button will turn RED and pulse when recording
   - You'll see "Listening..." indicator

2. **While Speaking**
   - Speak clearly into your microphone
   - Watch the live preview box below the textarea
   - Your words appear in real-time as you speak
   - Final text is automatically added to your answer

3. **Stop Recording**
   - Click the RED stop button (⏹️)
   - Recording stops immediately
   - All recognized text is saved in your answer

### Visual Indicators

| Indicator | Meaning |
|-----------|---------|
| 🎤 Gray microphone | Ready to record |
| 🔴 Red pulsing button | Currently recording |
| "Listening..." box | Live speech preview |
| Pulsing microphone icon | Actively processing speech |

### Tips for Best Results

✅ **DO:**
- Speak clearly and at a moderate pace
- Use a quiet environment
- Allow microphone access when prompted
- Pause briefly between sentences
- Review the interim results as you speak

❌ **DON'T:**
- Speak too fast or mumble
- Use in noisy environments
- Forget to grant microphone permissions
- Submit while still recording (it auto-stops)

### Keyboard Shortcuts

- **Type manually**: Just start typing in the textarea
- **Voice + Type**: You can combine both methods
- **Edit recognized text**: Click in textarea and edit as needed

### Troubleshooting

#### "Microphone access denied"
**Solution**: 
1. Click the lock icon in your browser's address bar
2. Allow microphone access
3. Refresh the page
4. Try again

#### "Speech recognition not supported"
**Solution**: 
- Use Chrome, Edge, or Safari browser
- Firefox doesn't support Web Speech API

#### "Network error"
**Solution**: 
- Check your internet connection
- Speech recognition requires internet
- Try again when connection is stable

#### Recording stops automatically
**Cause**: No speech detected for a while
**Solution**: Just click the microphone button again to restart

### Interview Process

1. **Question Display**
   - Read the question carefully
   - Note the category and difficulty level
   - Use the 🔊 speaker button to hear the question

2. **Answer Input**
   - Type your answer OR
   - Use voice input OR
   - Combine both methods

3. **Submit Answer**
   - Click "Submit Answer" button
   - Wait for AI evaluation (shows "Evaluating...")
   - Review your score and feedback

4. **Navigation**
   - Auto-advances to next question after 2.5 seconds
   - Use "Previous" button to review past answers
   - Use "Next Question" to skip ahead
   - Click "Complete Interview" on the last question

### Interview Features

#### Timer
- Displayed in top-right corner
- Turns RED when less than 30 seconds remain
- Pulses when time is running out

#### Progress Bar
- Shows current question number
- Visual progress indicator
- Total questions count

#### Proctor Warnings
- Tab switching is detected
- Warnings are logged
- Displayed in the header

#### Evaluation Display
- Overall score (X/10)
- Detailed metrics breakdown
- AI feedback and suggestions
- Visual progress bars for each metric

### Best Practices

1. **Prepare Your Environment**
   - Quiet room
   - Good microphone
   - Stable internet
   - Supported browser

2. **During the Interview**
   - Read questions carefully
   - Think before answering
   - Use voice input for faster responses
   - Review your answer before submitting

3. **Technical Setup**
   - Test microphone before starting
   - Check browser permissions
   - Ensure good internet connection
   - Use headphones to avoid echo

### Privacy & Security

- 🔒 Voice data is processed by browser's built-in API
- 🌐 Requires internet for speech recognition
- 🎤 Microphone access is required
- 🔐 No audio is recorded or stored
- ✅ Only text transcription is saved

### Getting Help

If you experience issues:
1. Check browser console (F12) for errors
2. Verify microphone permissions
3. Test in a different browser
4. Check internet connection
5. Refresh the page and try again
